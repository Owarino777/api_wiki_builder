# Livrables - Rendu Prof

## Objectif

Ce dossier centralise les livrables attendus pour la partie "specs + UML + architecture + API".

Le contenu est base sur :

- le code reel du projet (`routes`, `controllers`, `models`, `migrations`)
- la documentation deja presente dans `doc/`
- le suivi pedagogique fourni (Laravel, API, middleware, specs, use cases, diagrammes)

## Contenu

- `01_audit_livrables.md` : verification de conformite des livrables
- `02_specifications_fonctionnelles.md` : spec fonctionnelle exploitable
- `03_specifications_techniques.md` : spec technique backend/API
- `04_user_stories.md` : backlog user stories
- `05_use_cases.md` : use cases rediges pour rendu
- `06_plan_validation.md` : plan de tests et preuves de validation
- `postman_collection_template.json` : collection Postman importable
- `uml/` : diagrammes UML 2.5 (format PlantUML)

## Note UML 2.5

Les diagrammes sont fournis en source `.puml` :

- lisibles textuellement par le correcteur
- facilement exportables en PNG/SVG/PDF
- versionnables dans Git

Voir `uml/README.md` pour l'export.
